📶 BLE 命令测试

逐条下发固件已实现的 CHAR3 命令并观察响应。命令帧统一为 55 AA LEN_H LEN_L CMD DATA CRC 0D， 响应经 FFE4 通知回传；异步命令（刷纯色 / 擦除）会先回 0x01 受理，完成后推送 0x02 完成。

⚠️ 当前浏览器不支持 Web Bluetooth API。请使用 Chrome / Edge（HTTPS 或 localhost 访问）。
